# 개발 로드맵

## M0 — 기반 구축

- [x] Fabric 26.2 프로젝트 생성
- [x] 세계관과 기술 설계 문서화
- [x] Soul Signature 도메인 모델 생성
- [ ] CI 빌드와 첫 개발 버전 태그

완료 조건: 깨끗한 환경에서 빌드되고 개발 클라이언트가 실행된다.

## M1 — Soul Sight 회색 상자 (1~2주)

- [ ] 액티브 키와 집중 게이지
- [ ] 서버 의도 상태 및 네트워크 동기화
- [ ] 여섯 의도의 임시 입자·사운드 표현
- [ ] 개발용 테스트 몹과 디버그 명령

완료 조건: 처음 보는 플레이어가 튜토리얼 후 세 의도를 70% 이상 구분한다.

## M2 — Chapter 1 세로형 데모 (3~5주)

- [ ] 잿빛 마을 소형 구조물
- [ ] 죽음 너머의 시선 흔적 세 종류
- [ ] 바로크 모델·애니메이션·4개 패턴
- [ ] Ash 수집과 첫 성장 선택
- [ ] 15~20분 플레이 흐름

완료 조건: 치명적 버그 없이 시작부터 바로크 처치까지 완료할 수 있다.

## M3 — 콘텐츠 확장

- [ ] 올드리치 무기 전환 보스전
- [ ] 루멘의 플레이어 빌드 모방
- [ ] 혼령군주 능력 반전 프로토타입
- [ ] 멀티플레이 동기화 및 밸런스

## 의사결정 게이트

- M1 플레이테스트가 실패하면 아트 제작보다 신호 문법을 다시 설계한다.
- M2 완주율이 낮으면 지역 규모를 늘리지 않고 탐색 동선을 줄인다.
- 혼령군주 프로토타입이 독립적으로 재미있을 때만 전체 Chapter 3 제작에 들어간다.
