# ASH TRACER

> 육체보다 먼저 흔들리는 영혼을 읽고, 전투의 흐름을 지배한다.

**ASH TRACER**는 적의 공격 방향을 알려주는 모드가 아니다. 플레이어는 살아 있는 존재의 영혼이 수축하고, 갈라지고, 망설이는 방식을 관찰해 그 의도를 추론한다. 죽은 존재가 남긴 **사념의 재(Ash)**를 따라가며 혼령제국에 패배한 솔라리스 성전단장 **루미너스**의 힘과 기억을 되찾는다.

## 첫 번째 플레이 가능 목표

첫 공개 빌드는 15~20분 분량의 세로형 데모다.

1. 잿빛 마을에서 `죽음 너머의 시선`으로 세 개의 사념 흔적을 추적한다.
2. 하급 악령을 상대로 `생명을 비추는 빛`의 영혼 의도 읽기를 학습한다.
3. 주민의 감정을 수탈하는 **영혼 징수관 바로크**와 전투한다.
4. 모은 Ash로 첫 능력 강화를 선택하고, Chapter 2의 문을 연다.

## 전투 원칙

- 색 하나가 정답이 되지 않는다. 형태, 맥동 주기, 이동 방향, 소리를 함께 읽는다.
- 능력은 정보를 주지만 승리를 자동화하지 않는다. 집중 게이지와 시야 제한이 대가다.
- 일반 몬스터도 같은 문법을 쓰고, 보스는 그 문법을 조합하거나 거짓 신호를 낸다.
- 최종 보스 혼령군주는 `생명을 비추는 빛`으로 읽을 수 없다. 플레이어는 빛을 끄고 `죽음 너머의 시선`을 선택해야 한다.

## 기술 기준

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3 / Fabric API 0.158.0+26.2
- Java 25

버전은 Fabric 공식 예제 모드의 `26.2` 브랜치를 기준으로 고정했다.

```powershell
.\gradlew.bat runClient
```

설계 문서는 [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md), [`docs/TECHNICAL_DESIGN.md`](docs/TECHNICAL_DESIGN.md), [`docs/ROADMAP.md`](docs/ROADMAP.md)를 참고한다.

## 상태

현재 단계는 **Pre-Alpha / 기획 및 기반 구축**이다. 첫 목표는 Soul Sight의 읽기 문법을 회색 상자 프로토타입으로 검증하는 것이다.
